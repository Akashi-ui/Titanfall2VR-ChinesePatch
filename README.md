## 安装方法

请按此顺序安装**安装Titanfall 2  → 安装 VR 模组 → 安装本中文补丁**

1. 安装 Titanfall 2
2. 使用[VR 模组安装程序](https://github.com/CircuitLord/CircuitLordVRModInstaller/releases/latest)安装Titanfall 2 VR 模组。
3. 从[最新版本](https://github.com/Akashi-ui/Titanfall2VR-ChinesePatch/releases/latest)找到(`Titanfall2VR-Chinese-Setup-版本号.exe`)并下载。
4. 退出游戏并运行安装程序。确认自动找到的游戏文件夹是否正确，然后点击 **检查补丁更新并启动游戏(带有中文补丁)**。如果找不到该文件夹​​，请点击 **浏览**手动指定Titanfall 2的安装文件夹，如果提示需要管理员权限，点击允许。
5. 这里应该写有关自动更新的事，但我没有弄好，我也不知道我能不能弄好
6. 请在游戏内的 **设置 → 声音** 里开启 **字幕** 来显示对话字幕

## 删除方法

关闭游戏后，点击补丁安装器里的 **移除中文补丁**。
